# Hi, I'm thebluecatbot

I build machine learning projects and web apps, with a focus on language models, retrieval (RAG) and data analysis.

**Tools I've used in these projects:** Python, TypeScript, FastAPI, Flask, React, Pandas, scikit-learn, FAISS, Firebase, Power BI

## Featured projects

### Language models and AI
- **[nanogpt-dna](https://github.com/thebluecatbot/nanogpt-dna):** DNA language models built on nanoGPT. Seven architecture variants trained on yeast and *E. coli* genomes, compared on bits-per-base and biological tasks.
- **[compass-journal](https://github.com/thebluecatbot/compass-journal):** a private journal with Gemini that turns closed entries into themes, decisions and next actions. Built for the Google Cloud Gen AI Academy APAC 2026.
- **[predii-spec-extractor](https://github.com/thebluecatbot/predii-spec-extractor):** a RAG pipeline that extracts vehicle specifications from service manual PDFs, tested on an 852-page workshop manual.
- **[pdf-rag-qa](https://github.com/thebluecatbot/pdf-rag-qa):** source-grounded Q&A over research papers using FAISS, MiniLM embeddings and Groq.
- **[bert-text-classification](https://github.com/thebluecatbot/bert-text-classification):** BERT fine-tuning and a from-scratch transformer on a 43-label dataset.

### Applied ML and analytics
- **[yoga-asana](https://github.com/thebluecatbot/yoga-asana):** a FastAPI service that returns personalised yoga poses and routines (B.Tech project).
- **[movie-review-sentiment-classifier](https://github.com/thebluecatbot/movie-review-sentiment-classifier):** an end-to-end sentiment pipeline using TF-IDF and LinearSVC.
- **[restaurant-revenue-analytics](https://github.com/thebluecatbot/restaurant-revenue-analytics):** revenue analysis of 13 months of restaurant POS data with Pandas and Power BI.

### Web apps and tools
- **[movie-ticket-booking](https://github.com/thebluecatbot/movie-ticket-booking):** a seat-level ticket booking system built with Flask and SQLite.
- **[youtube-video-summarizer](https://github.com/thebluecatbot/youtube-video-summarizer):** a Chrome extension that summarises YouTube transcripts with one click.
